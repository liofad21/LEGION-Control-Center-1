# Legion Control Center + Raven

لوحة تحكم بديلة لـ Quick Settings بتصميم Legion الأحمر + المساعدة الذكية **Raven** (Gemini).

## الميزات
- اسحب من أعلى الشاشة (أو افتح لوحة الإشعارات) فتظهر اللوحة؛ اسحب لفوق لقفلها.
- ساعة وتاريخ حيّين، بطارية/CPU/GPU/رام/حرارة/واي فاي قراءات حقيقية من النظام.
- Raven: لمس الشاشة 3 مرات ورا بعض يظهرها، و3 تاني يخفيها. بتنادي عليك "ريو"، بصوت أنثوي ناعم، وبتنفّذ أوامر التابلت.
- كلمة التنبيه "RAVEN" (خدمة Foreground بإشعار دائم) — تشغيل/إيقاف من التطبيق.
- ترجمة التطبيقات الصينية للإنجليزي فوق الشاشة (OCR-free عن طريق Accessibility) — تشغيل/إيقاف.
- إدارة حرارة: خفض معدل التحديث تلقائيًا عند السخونة العالية + نصايح.
- أدوات اللعب: Game Assistant، شريط عايم، Key Mapping لدراع، منقر تلقائي.

## الموديلات (في `GeminiClient.kt`)
الدماغ: `gemini-3.5-flash-lite` ثم بدائل (`gemini-3.6-flash`, `gemini-3.8-flash`). الصوت: `gemini-3.8-flash-lite-tts` ثم `gemini-3.8-flash-tts`، وبعدها صوت أندرويد.

## البناء
GitHub Actions (`.github/workflows/build.yml`) أو Android Studio. minSdk 26.
